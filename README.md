# ServX - Professional Service Booking & Recommendation Platform

ServX is a full-stack web application designed to connect users with verified local service professionals (such as electricians, teachers, cleaners, and technicians) using an intelligent recommendation engine.

## Tech Stack

* **Backend:** FastAPI, SQLAlchemy, SQLite, Uvicorn, Python-Jose (JWT Auth)
* **Data Processing & ML:** Pandas, Scikit-Learn (Recommendation Engine)
* **Frontend:** React, Vite, Tailwind CSS / Modern CSS

## Features

* **User Authentication:** Secure JWT-based authentication supporting distinct accounts for customers and professionals.
* **Smart Search & Filtering:** Filter professionals by category/profession and location with instant results.
* **ML-Powered Recommendations:** Intelligent scoring system to rank and recommend the best-suited professionals based on user preferences.
* **Dataset Integration:** Automated CSV import utility for loading and managing professional records.
* **Booking Management:** Seamless scheduling system for service requests and tracking status.
